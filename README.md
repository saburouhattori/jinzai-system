# 人材管理システム (Jinzai System)

## 概要 (Overview)

Google Apps Script (GAS) と Google スプレッドシートを活用した人材紹介事業（Smile Dream Co.,Ltd.）向けの管理システムです。
候補者（登録者）の管理、求人案件の管理、面接から採用（内定）までのプロセスを一元管理し、業務の効率化を図ります。日本およびミャンマー拠点のスタッフが共同で運用することを想定して設計されています。

## 主な機能 (Features)

* **候補者管理**:
  「登録者マスタ」への新規登録、更新、削除。顔写真データを含んでいても高速に一括更新可能なロジックを実装。また、新規登録時には「登録日」をシステム日付で自動入力します。名前変更時には関連する案件管理側の表記も自動置換されます。

* **年齢自動計算**:
  スプレッドシートの DATEDIF 関数と ARRAYFORMULA を活用し、生年月日から満年齢をリアルタイムに自動計算。メンテナンスフリーな運用を実現。

* **案件・採用管理**:
  求人案件の登録、修正、削除機能。および案件に対する候補者の面接結果（採用・不採用・辞退・取消）の登録・修正機能。過去案件の結果修正時には、他案件で既に採用されている候補者や「辞退」「不採用」ステータスの候補者が誤ってリセットされないよう保護されます。また、案件削除時には関連するマスタの面接履歴やステータスを自動でロールバックします。

* **面接履歴と内定日の自動追記**:
  「面接結果の登録」実行時に、該当案件で面接を受けた全候補者（採用・不採用問わず）の「面接履歴」と結果を、「登録者マスタ」へ自動で改行追記します。また、採用時は「内定日」も自動的にマスタへ反映されます。

* **入国・入職日の一括登録**:
  案件IDを指定して当該案件の採用者のみを自動抽出し、全員共通の日付セットまたは個別の微調整によって、「登録者マスタ」の入国日・入職日を一括で登録・更新する機能。

* **自動リスト同期 (動的マッピング)**:
  登録者マスタの更新内容を「採用者一覧」「未採用者一覧」「簡易リスト」へ自動同期。ヘッダー名（1行目の文字列）をキーにしてデータを自動振り分けするため、列の追加や移動にも柔軟に追従します。また、「案件管理」シートの「面接結果詳細」および「内定日」を正本（SSoT）として、「登録者マスタ」「採用者一覧」「未採用者一覧」のステータス・採用事業者・内定日を一括反映します（「辞退」「不採用」ステータスは保護）。

* **直感的なUI / 待機表示**:
  データの送受信や同期など、時間のかかる非同期処理中には画面全体を覆うローディングスピナーを表示し、システムの状態を視覚的にフィードバックします。

* **ファイル・フォルダ自動連携機能（アップロード・スマートチップ化）**:
  * PCからのファイル直接アップロードに対応。自動的に「案件ID_事業者名」のフォルダを作成・特定し、ドライブへ保存してスプレッドシートと連携します。
  * 既存のGoogleドライブURL（ファイル・フォルダ）を入力・検索して追加することも可能。URLがシートに登録されると、自動的に名前を取得しファイルは「📄」、フォルダは「📁」のアイコン付きでスマートチップ風に変換します。

* **履歴書・簡易リスト生成**:
  候補者IDを指定して、提出用の履歴書や簡易リストを自動生成する機能。

* **支払い管理連携（外部連携）**:
  取引先である株式会社Funtoco様の外部シート「海外ミャンマー管理リスト【Funtoco】」へ、案件管理で確定した採用者情報をボタン一つで同期。
  同一登録者が別の案件で既に登録されている場合の重複警告機能を搭載し、Funtoco側で入力された入国日・金額等の業務データは保護しつつ、基本情報（内定日・入国日・入職日含む）を安全に更新可能。また、案件側で採用取り消しや辞退があった場合、連携先シートからも対象者を自動検知して削除する自動クレンジング機能を搭載しています。

## メニュー構成と標準業務フロー (Menu & Workflow)

スプレッドシート上部のカスタムメニューは、日常業務の流れ（時系列）に沿って以下の3つに分類・番号付けされています。

### 1. メニュー構成
* **`1. 登録者マスタ管理`**
  * `1. 候補者の新規登録`
  * `2. 登録者データの修正・更新`
  * `3. 登録者データの削除`
* **`2. 案件・採用管理`**
  * `1. 案件の新規登録`
  * `2. 簡易リスト作成`
  * `3. 履歴書作成`
  * `4. 案件情報の修正・削除`
  * `5. 面接結果の登録`
  * `6. 面接結果の修正・更新`
  * `7. 内定後の追加情報登録`
  * `8. 入国日・入職日の一括登録`
* **`3. 管理者用（マスタ・同期）`**
  * `1. 事業者の新規登録`
  * `2. 採用・未採用リストの同期`（※開発中の一時的な手動同期メニュー）
  * `3. 支払い管理シートへ同期（Funtoco）`（※開発中の一時的な手動同期メニュー）

### 2. 標準業務フロー（システム利用手順）

| ステップ | 業務タイミング | 操作メニュー | 主な作業内容とシステム処理 |
| :--- | :--- | :--- | :--- |
| **Step 1**<br>候補者登録 | 新規候補者の募集・面談後 | `1. 登録者マスタ管理`<br>＞ `1. 候補者の新規登録` | 候補者の基本情報・学歴・職歴・特定技能要件・顔写真を「登録者マスタ」に登録する（ステータスは自動で「未採用」、登録日は当日日付が自動付与される）。<br>※既存データの修正時は `2. 登録者データの修正・更新` を使用する。 |
| **Step 2**<br>案件登録と<br>提案書類作成 | 求人依頼・候補者選定時 | `2. 案件・採用管理`<br>＞ `1. 案件の新規登録`<br>＞ `2. 簡易リスト作成`<br>＞ `3. 履歴書作成` | 1. 受入企業（事業者名）・技能分野・エントリーする候補者IDを指定して案件を作成する（関連ファイルのアップロードも可能）。<br>※新しい事業者の場合は、先に `3. 管理者用` ＞ `1. 事業者の新規登録` を行う。<br>2. 受入企業へ提出するための「簡易リスト」および各候補者の「履歴書」を出力する。 |
| **Step 3**<br>面接日設定 | 面接日程の確定時 | `2. 案件・採用管理`<br>＞ `4. 案件情報の修正・削除` | 対象の案件IDを検索して読み込み、確定した「面接日」を入力し、ステータスを「面接準備」等に更新する。 |
| **Step 4**<br>面接結果登録 | 面接実施・合否判明時 | `2. 案件・採用管理`<br>＞ `5. 面接結果の登録` | 案件IDを検索し、採用された候補者にチェックを入れて「内定日」を入力し登録する（全員不採用の場合は「採用者なし」にチェック）。<br>「案件管理」の面接結果詳細が更新され、全候補者のマスタに面接履歴とステータス（採用/未採用）・内定日が自動反映される。<br>※登録後に結果の変更・辞退・取消が生じた場合は `6. 面接結果の修正・更新` から変更する。 |
| **Step 5**<br>在留資格申請<br>情報の登録 | 内定後・申請準備時 | `2. 案件・採用管理`<br>＞ `7. 内定後の追加情報登録` | 採用された候補者の管理番号（SD-XXXX）で検索し、在留資格申請に必要なパスポート情報・送り出し機関・出入国歴・日本在住親族などの詳細情報を登録する。 |
| **Step 6**<br>入国・入職日<br>の一括登録 | 入国・配属スケジュール確定時 | `2. 案件・採用管理`<br>＞ `8. 入国日・入職日の一括登録` | 案件IDで当該案件の採用者一覧を呼び出し、確定した「入国日」「入職日」を一括セット（または個人ごとに微調整）して保存する。 |
| **Step 7**<br>外部シート同期 | 定期・情報更新後 | `3. 管理者用（マスタ・同期）`<br>＞ `3. 支払い管理シートへ同期（Funtoco）` | 確定した採用者情報や内定日・入国日・入職日を、Funtoco様の外部シート「支払い管理」へ同期する。 |

## システム構成 (System Structure)

### スプレッドシート（データベース）

* **登録者マスタ**: 全候補者のベースデータ（ID: SD-XXXX）
* **案件管理**: 求人案件データ（ID: JOB-XXXX）
* **リスト・出力用**: 未採用者一覧, 採用者一覧, 簡易リスト, 履歴書, 面接管理, 操作マニュアル
* **各種マスタ**: 事業者マスタ, 送り出し機関マスタ, 日本語学校マスタ, 企業情報, 面談用質問

### Google Apps Script (バックエンド・フロントエンド)

* `01_共通・メニュー.gs` / `JS_Common.html` : 共通処理・UIの制御・メニュー構築
* `02_候補者管理.gs` / `HTML_Candidate.html` / `JS_Candidate.html` : 候補者データ操作
* `03_案件管理.gs` / `HTML_Job.html` / `JS_Job.html` : 案件データの登録・更新・削除・候補者名連動置換
* `04_事業者管理.gs` / `HTML_Company.html` / `JS_Company.html` : 事業者データ操作
* `05_マスタ連携・その他.gs` : リストの自動同期（syncListSheets）、案件管理からの一括再構築（rebuildMasterFromJobSheet）、辞書生成などの補助機能
* `06_外部連携.gs` : 取引先（Funtoco等）の外部システムとのデータ同期・転記・自動削除処理
* `07_履歴書作成.gs` : 履歴書の自動出力処理
* `08_ドライブ連携.gs` : Googleドライブ内のファイル検索・フォルダ自動作成・アップロード保存、スマートチップ変換処理
* `09_面接・採用管理.gs` / `HTML_Hire.html` / `JS_Hire.html` : 面接対象者の取得、面接結果の登録・修正、内定日の設定、入国・入職日の一括登録、全対象者の面接履歴への自動追記・ロールバック処理
* `10_マニュアル生成.gs` : スプレッドシート内に「操作マニュアル」シートを自動生成・書式設定する保守用スクリプト

### HTML / UIファイル
* `MainSidebar.html` : メインUIの土台。各モードの表示切り替えに使う中心ファイル。
* `Sidebar_CSS.html` : UI共通スタイル。
* `HTML_Candidate.html` / `JS_Candidate.html` : 候補者管理画面のHTMLおよびクライアント側スクリプト。
* `HTML_Job.html` / `JS_Job.html` : 案件管理画面のHTMLおよびクライアント側スクリプト。
* `HTML_Hire.html` / `JS_Hire.html` : 面接結果登録・修正および入国・入職日一括登録画面のHTMLとスクリプト。
* `HTML_List.html` / `JS_List.html` : 簡易リスト作成画面のHTMLおよびスクリプト。
* `HTML_Company.html` / `JS_Company.html` : 事業者管理画面のHTMLおよびスクリプト。
* `JS_Common.html` : UI共通のクライアント側スクリプト。
